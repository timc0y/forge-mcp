# ADR 0005: MCP SDK version adapters

**Status:** accepted

Production uses `@modelcontextprotocol/sdk` 1.29.0 through `mcp-adapter-v1`. The v2 beta adapter is isolated and disabled. The same tool contract suite must pass before migration; production changes only after v2 and the 2026-07-28 specification are stable and real-client compatibility is proven.

# ADR 0005: MCP SDK version adapters

- **Status:** accepted
- **Current:** Production uses `@modelcontextprotocol/sdk` 1.29.0 via `mcp-adapter-v1`.
- **Beta:** v2 adapter is isolated and disabled.
- **Migration Requirements:** Same tool contract suite must pass. Production changes require v2 and 2026-07-28 spec stability plus proven real-client compatibility.

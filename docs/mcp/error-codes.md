# Forge error codes

Forge returns stable errors independent of providers: `FORGE_AUTH_REQUIRED`, `FORGE_PERMISSION_DENIED`, `FORGE_WORKSPACE_NOT_FOUND`, `FORGE_WORKSPACE_NOT_READY`, `FORGE_WORKSPACE_CONFLICT`, `FORGE_STALE_REVISION`, `FORGE_LEASE_REQUIRED`, `FORGE_APPROVAL_REQUIRED`, `FORGE_APPROVAL_EXPIRED`, `FORGE_COMMAND_TIMEOUT`, `FORGE_COMMAND_BLOCKED`, `FORGE_OUTPUT_TRUNCATED`, `FORGE_FILE_CONFLICT`, `FORGE_PATCH_REJECTED`, `FORGE_PROCESS_NOT_FOUND`, `FORGE_PREVIEW_UNAVAILABLE`, `FORGE_GIT_DIRTY`, `FORGE_GIT_PUSH_BLOCKED`, `FORGE_PROVIDER_UNAVAILABLE`, `FORGE_QUOTA_EXCEEDED`, `FORGE_SNAPSHOT_INCOMPATIBLE`, `FORGE_VALIDATION_FAILED`, and `FORGE_INTERNAL_ERROR`.

Errors contain code, safe message, retryability, operation ID when available and bounded redacted details. Provider IDs, stack traces and secrets are excluded.

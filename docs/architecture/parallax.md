# Parallax integration

Parallax is Forge's first-party client, not the execution platform. It can use either the public MCP contract or a Cloudflare service binding into the same application services.

The native path may optimize identity propagation, event delivery, preview embedding and approvals, but cannot duplicate policy or workspace logic. Parallax receives workspace-scoped Forge capabilities, never GitHub installation tokens, Sandbox credentials or unrestricted internal bindings.

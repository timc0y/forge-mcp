# Documentation

Forge connects your conversation to GitHub. Read the project, save a plan or
make a change, then pick up the work in your coding tools.

## Run your own Forge

Start with the [self-hosting guide](./self-hosting.md). It covers your GitHub
App, Cloudflare account, access settings and first commit. Forge is
[MIT licensed](../LICENSE); you pay your own hosting and client costs.

## Use Forge

[Using Forge](./using-forge.md) covers connecting your client, choosing
repositories, reading files and making changes.

## Look after your instance

[Operating Forge](./operating-forge.md) covers configuration, updates, costs and
recovery. Use the [release checklist](./going-live.md) when updating, and the
[account-deletion guide](./account-deletion.md) for requests to remove user data.

## Understand or contribute

The [context engine](./plans/context-engine.md) explains how Forge reads source.
[SIMPLE.md](../SIMPLE.md) records the design constraints, and the
[product route](./plans/product-route.md) explains the self-hosting approach.

See [Contributing](../CONTRIBUTING.md) for development setup and
[Security](../SECURITY.md) for private reporting. The [research](./research/),
[design history](./research/forge-history-tool-learnings.md) and
[earlier V1 design](./plans/forge-v1.md) give background to the current system.

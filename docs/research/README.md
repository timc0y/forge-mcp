# Research

Dated investigations, rejected alternatives and experimental Cloudflare features.
Nothing here is required for the first complete product; experiments are gated by
`feature-flags.json` maturity and must document use case, benefit, complexity,
cost, lock-in, failure mode and exit criteria.

Existing investigations: Cloudflare Sandbox, Workflows, Code Mode, Browser Run,
Agents, OAuth, GitHub App, MCP TypeScript SDK, MCP Apps, infrastructure options,
Forge 0.5 platform options, and the adoption register. Superseded notes are kept
and marked, not deleted.
